# Security Policy

請透過 GitHub 的 [Private vulnerability reporting](https://github.com/tntrock/msu-inspector/security/advisories/new) 私下回報安全問題，不要開公開 issue。

Please report security issues privately via [GitHub private vulnerability reporting](https://github.com/tntrock/msu-inspector/security/advisories/new) instead of opening a public issue.

只有最新版本會收到修補。 Only the latest release receives fixes.
